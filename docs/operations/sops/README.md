# Índice de SOP operativos

Los SOP se crean y validan dentro de la entrega que habilita el proceso. E0 define el índice y la plantilla; no declara listos procedimientos que aún no fueron pilotados.

| Proceso | Entrega de primer SOP | Digital | Imprimible | Estado |
| --- | --- | --- | --- | --- |
| Apertura, olas y picking | E1 | pendiente | pendiente | planificado |
| Fotos, paquetes y aprobación | E2 | pendiente | pendiente | planificado |
| Agente e impresión interna | E3 | pendiente | pendiente | planificado |
| Lotes, tracking y despacho | E4 | pendiente | pendiente | planificado |
| App, dispositivos y alertas | E5–E7 | pendiente | pendiente | planificado |
| Stock, ubicaciones y movimientos | E8–E12 | pendiente | pendiente | planificado |
| Recepción y putaway | E14–E15 | pendiente | pendiente | planificado |
| Conteos y ajustes | E16–E17 | pendiente | pendiente | planificado |
| Excepciones y garantías | E18–E19 | pendiente | pendiente | planificado |
| Taller | E20–E21 | pendiente | pendiente | planificado |
| Diagnóstico y recuperación | E23 | pendiente | pendiente | planificado |

Cada SOP debe incluir propósito, roles/permisos, precondiciones, pasos, controles, excepciones, contingencia offline, escalamiento, cierre, auditoría y fecha de práctica. La versión imprimible debe funcionar sin enlaces y mostrar código/fecha de versión.
