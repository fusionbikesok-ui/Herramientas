# Índice de SOP operativos

Los SOP se crean y validan dentro de la entrega que habilita el proceso. E0 define el índice y la plantilla; no declara listos procedimientos que aún no fueron pilotados.

Cada SOP debe incluir propósito, roles/permisos, precondiciones, pasos, controles, excepciones, contingencia offline, escalamiento, cierre, auditoría y fecha de práctica. La versión imprimible debe funcionar sin enlaces y mostrar código/fecha de versión.
